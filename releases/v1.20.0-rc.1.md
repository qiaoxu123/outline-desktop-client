# v1.20.0-rc.1 — 论文库与讨论区体验优化

此版本供安装测试，基于 v1.19.1。主界面继续使用官方 Outline Web，扩展页面沿用官方主题与编辑器；不修改服务器数据库或现有文档。

## 显示与交互

- 论文库、讨论区统一页面宽度、工具栏、筛选按钮和列表间距，适配浅色/深色主题与窄窗口。
- 热门领域默认显示 8 项，可展开；每页最多渲染 50 行，搜索仍覆盖整个索引。
- 过滤无结果时可一键清除筛选；区分尚无内容、加载中、更新失败，保留缓存列表。
- 修复第一次点击阅读状态仍停留“未读”的问题：未读 → 在读 → 已读 → 未读。
- 修复在点赞、评分、阅读状态等子控件按 Enter/Space 时误打开文档的问题。
- 修复“我赞过”数量将空值也计入的问题；修改个人评分时保留其他成员的评分贡献。
- 讨论标题正确截断；头像懒加载；未知统计显示占位符；发帖支持中文输入法，不在组合输入时误提交。
- 发布讨论后直接进入官方文档编辑器，不等待整个论坛索引重建。

## 加载效率与稳定性

- 合并同工作区的并行索引刷新，返回仍在加载的论文库时订阅原任务结果，避免页面卡在“刷新中”。
- 集合发现与集合树短期缓存/请求合并；集合列表读取全部分页，避免后续集合漏入论文库。
- 保留已有快照、增量元数据与有界并发；手动刷新会重新发现论文来源。
- 团队切换时重建扩展页面状态，避免上一团队的本地列表残留。
- 同一客户端内的点赞/评分 WebDAV 写入串行执行，读取失败时禁止以空数据覆盖远端；同步失败明确提示。
- 修复安装包中运行时配置提前固化，以及 Vite 提取的 CSS 未注入启动页面的问题。
- 校正静态资源 MIME 类型；缺失资源返回 404，避免将 HTML 当作 JS/字体反复加载。

## 安装包与验证

提供 macOS（Apple Silicon / Intel）、Windows（x64 / ARM64）、Linux（x64 / ARM64），每种架构各两种包格式，共 12 个文件。

发布流程依次执行扩展逻辑回归测试、桌面 TypeScript 检查、正式构建、桌面测试、Web manifest/语言包/入口文件完整性检查；六种平台/架构独立打包，再检查文件数量、大小、容器签名与 SHA-256。

Release 先创建草稿，再重新下载所有安装包核对 SHA256SUMS.txt；全部通过后才发布。verification.json 记录构建 commit 与安装包摘要。

macOS 为 ad-hoc 签名；Windows 未配置商业代码签名。ARM64/Intel 兼容性与真实服务器交互仍请安装后验证；自动构建通过不等同于所有平台的人工验收通过。

## 建议测试

1. 安装对应架构；登录、退出、重启与切换工作区。
2. 浅色/深色主题、900px 窗口宽度，检查论文库/讨论区布局。
3. 打开论文库后立即离开再返回；反复切换页面，确认列表不清空、不重复完整扫描。
4. 搜索、领域、阅读状态、年份/月、最近浏览与分页组合。
5. 点赞、连续评分、取消评分；检查共享数据和错误提示。
6. 发帖、中文输入法、版块选择、置顶、官方评论与手动刷新。
7. 原有官方文档编辑、附件、标签页、随笔、AI 功能。

现有 WebDAV 文件协议没有服务器事务或 ETag 条件写入；本版解决同客户端并发，不宣称多台客户端同时写入完全无冲突。
