# v1.20.0-rc.3 — 修复工作区被误判为无效实例

本版包含 rc.2 的论文库、讨论区和刷新优化，重点修复“选择工作区”中合法地址被判定为无效的问题。

## 原因与修复

Outline 的 /api/auth.config 返回 { data: { providers: [...] } }，官方桌面桥接要求返回配置本身。此前主进程原样返回 HTTP JSON，校验器找不到顶层 providers，因此显示“这似乎不是有效的安装实例”。现在主进程先解包并验证配置，再交给官方 Web；保留 https://notes.jlu-mcns.site:224 等自定义端口。

仍然拒绝 HTTP 错误、非 JSON/异常结构以及网络失败，不会跳过有效性校验或新增证书例外。兼容已解包的配置格式及尚未配置认证提供者的实例。

## 自动验证

新增 10 项回归测试：标准 data 包装、自定义端口、直接配置、五类异常结构、HTTP 失败、网络失败、非 HTTP 地址。完整流程另执行原有 42 项 Web 测试和桌面测试、TypeScript、正式构建、657 个 Web 资源检查、六平台/架构打包，以及 12 个发布安装包的下载后 SHA-256 复核。实际结果以关联 Actions 为准。

## 安装验收

安装对应 macOS / Windows / Linux 的 x64 或 ARM64 包。进入“选择工作区”，输入 notes.jlu-mcns.site:224 或完整 HTTPS 地址，等待校验后点击“继续操作”；再检查登录与原有论文库、讨论区功能。真实网络、证书与账号登录仍需在你的设备上验证。

所有安装包附 SHA256SUMS.txt 和 verification.json；macOS 为 ad-hoc 签名，Windows 未配置商业代码签名。rc.2 更新说明见仓库 releases/v1.20.0-rc.2.md。
