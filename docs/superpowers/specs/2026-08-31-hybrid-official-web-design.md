# 官方 Web 主界面与本地扩展页混合架构设计

## 目标

当前激活的 Outline Server 作为官方 Web 主界面来源。文档、集合、搜索等核心能力由官方 Web 提供；个人笔记、论文库、讨论区继续由本地工程提供，并通过固定的原生侧边栏入口访问。

本阶段只支持当前激活的 Profile，不改变现有多 Profile 数据结构，也不要求扩展页面迁移到官方 Web。

## 架构

```text
Electron BrowserWindow
├── 本地 React 壳
│   ├── 原生侧边栏
│   │   ├── 官方 Web 主界面
│   │   ├── 个人笔记
│   │   ├── 论文库
│   │   └── 讨论区
│   └── 本地扩展页面容器
└── WebContentsView
    └── 当前 Profile 的 Outline Server Web 地址
```

使用 `WebContentsView` 承载官方 Web 内容，不使用 iframe。官方 Web 需要独立的浏览上下文、Cookie、导航和认证状态；`WebContentsView` 也能避免跨域 iframe 的 CSP、X-Frame-Options 和 Cookie 限制。

本地 React 壳负责布局和入口状态，主进程负责创建、定位、显示和隐藏远程 Web 内容视图。远程 Web 与本地扩展页面保持隔离，不注入或修改官方 Web 的 JavaScript。

## 路由与交互

- 进入“文档”“集合”“搜索”等主入口时，显示官方 Web 视图。
- 点击“个人笔记”“论文库”“讨论区”时，隐藏官方 Web 视图并渲染本地 React 路由。
- 再次点击官方 Web 主入口时，恢复远程视图，并保留其当前页面和登录状态。
- 当前激活 Profile 变化时，更新 Web 视图的目标服务器；切换期间先隐藏旧视图，避免内容串 Profile。
- 官方 Web 的外部链接由主进程按现有安全策略交给系统浏览器；官方 Web 内部导航保留在 Web 视图中。
- 本地扩展页面继续使用现有 IPC/API/WebDAV 逻辑，不依赖官方 Web 的 DOM 或内部实现。

## 认证与数据流

官方 Web 使用其自己的 Electron Session Cookie。当前工程已有 Profile 的服务器地址和 API 凭据，二者不直接互换；首次进入官方 Web 时，使用该服务器的正常登录流程建立网页会话。

如果 Profile 已保存可用于 API 的凭据，不自动把凭据注入网页。这样可以避免把 Bearer token 暴露给远程页面，并保持官方 Web 的认证边界。后续若要实现自动登录，应单独设计一次性授权或受限的认证桥，不在本阶段范围内。

本地扩展继续经主进程访问当前 Profile 的 Outline API。官方 Web 和扩展页面可以访问同一服务器的数据，但不共享前端缓存；扩展页面提交数据后按现有查询失效规则刷新。

## 主进程接口

新增一个远程 Web 视图管理器，职责限定为：

- 创建单个 `WebContentsView`；
- 设置目标 URL、尺寸、可见性和父窗口；
- 响应窗口 resize、页面切换和 Profile 切换；
- 处理内部/外部导航和加载失败；
- 在应用退出时销毁视图。

渲染进程只通过受控 IPC 发送“显示官方 Web / 显示本地页面 / 更新当前 Profile”意图，不直接操作远程 Web 的 `webContents`。

## 安全边界

- 仅允许当前 Profile 的合法 HTTP(S) origin 作为官方 Web 目标。
- 不允许远程页面调用本地扩展 IPC；本地桌面能力仍通过最小化的 preload bridge 暴露。
- 外部链接使用系统浏览器打开。
- 远程页面加载失败时显示本地错误状态，并提供重试；不自动降级到另一个 Profile。
- 不读取、修改或重新打包官方客户端的 ASAR。

## 实施范围

本次实现包含：

1. 本地壳的远程 Web 内容视图管理。
2. 侧边栏中官方 Web、个人笔记、论文库、讨论区四类入口的统一选中状态。
3. 当前 Profile 服务器地址到官方 Web URL 的映射。
4. 页面切换、窗口调整、Profile 切换、加载失败和重试。
5. 主进程和渲染进程的单元测试，以及构建后的静态验证。

本次不包含：

- 修改官方 Web 功能或注入脚本；
- 自动登录和跨应用 Cookie 迁移；
- 把本地扩展内容同步到官方 Web 导航树；
- 多个远程 Web 视图并行加载。

## 验收标准

- 启动后默认显示当前 Profile 对应的官方 Web。
- 官方 Web 中可以正常打开文档并使用其标题编辑功能。
- 侧边栏固定显示三个本地入口，点击后进入对应本地页面。
- 从本地页面返回官方 Web 后，远程页面状态和登录态仍保留。
- 调整窗口大小、切换 Profile、断网重试均不会出现旧 Profile 内容残留。
- 现有本地扩展页面测试、类型检查和 lint 全部通过。
